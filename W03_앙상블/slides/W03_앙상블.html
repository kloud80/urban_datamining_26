META ALGORITHM

자기 의지가
없는 알고리즘

“데이터를 이렇게 보겠다”는 주장이 없다. 그런 주장을 가진 알고리즘들을 한 단계 위에서 재조합할 뿐이다.

개별 모델이 수백~수천 개 필요하다. 신경망은 너무 오래 걸린다 — 그래서 빠른 나무와 궁합이 맞았다.
용어 정리

“모델이 다르다”는
무슨 뜻인가

이런 뜻이 아니다

회귀 + 의사결정나무를 합쳤다

이런 뜻이다

같은 나무인데 깊이가 다르다
같은 나무인데 학습한 데이터가 다르다

y = 0.1x + b 와 y = 0.2x + b 는 다른 모델이다. 숫자 하나만 달라도.
오늘의 질문

알고리즘도 하나, 데이터도 하나.
모델을 여러 개 어떻게 얻는가?

몇 번을 돌려도 똑같은 나무가 나온다.

방법은 둘뿐

나란히 갈까, 이어달릴까

투표 방식

한 표는 한 표인가, 확신을 셀 것인가

어느 쪽이 옳다고 아무도 정할 수 없다. 이렇게 모델 바깥에서 정해 주는 값을 하이퍼파라미터라고 한다.

BIAS · VARIANCE

어디에 무엇을 쓰나

방법 ① K-FOLD

데이터를
돌려가며 쓴다

5조각으로 나눠 하나씩 테스트로 쓰면 모델 5개가 나온다.

한계 — fold 를 늘리면 테스트 데이터가 줄어든다. 모델을 100개, 만 개 얻을 수는 없다.
방법 ② BOOTSTRAP

중복을 허용해
다시 뽑는다

같은 확률로 매번 다시 뽑는다. 같은 데이터가 두 번 들어와도 된다.

장점 — 서로 다른 데이터셋을 무제한으로 만들 수 있다. 만 개도 십만 개도.
BAGGING

Bootstrap Aggregating

중복 추출로 데이터셋을 여러 개 만들고 → 나무를 각각 학습시키고 → 투표한다. 이름이 곧 설명이다.

도시 데이터 사례

서울 S-DoT
도시데이터 센서

전봇대 2m 높이에 1,400여 개. 한 시간 단위로 값이 들어온다.

종속변수 — 그 시각 센서들 중 상대적 고온 / 저온
독립변수 — 반경 200m 안의 연속지적도 토지이용 + 건축물 주용도 면적 비율
깊이 3짜리 나무를 모으면

약한 나무
20그루가
강해진다

깊이는 그대로 3인데 테스트 정확도가 함께 올라간다 — 과적합 없이 좋아졌다는 뜻이다.

다만 무한정 늘린다고 계속 좋아지지는 않는다.

거래

정확도를 얻고 해석력을 잃는다

얻은 것

정확도 · 일반화 · 과적합 완화
그리고 병렬 연산이 가능하다

잃은 것

나무 하나는 분기를 따라가면 설명이 됐다.
이제 20개 모델의 분기를 다 설명해야 한다.

정확도를 좇을수록 사람이 이해할 수 있는 영역이 줄어든다. 이 거래는 앞으로 계속 나온다.
배깅의 장점

무엇이 도시의 온도를 가르는가

모든 나무가 모든 변수를 볼 수 있었으니 중요도를 그대로 합산할 수 있다. 노트북 실행 결과 · 변수 110개 중 상위

배깅의 한계

다 똑같은
거수기가 된다

데이터를 아무리 랜덤하게 뽑아도 가장 잘 나누는 변수가 매번 첫 분기를 차지한다.

서로 다른 주관을 가진 사람들이 투표해야 뜻이 있는데 — 다 같은 답을 낸다.
RANDOM FOREST · 2001

변수까지 랜덤하게 뽑는다

110개 중 다섯 개만 주고 그 안에서 나누라고 한다 — 나무마다 다른 관점이 생긴다.

새로 생긴 문제

참여할 기회도 못 받았는데
중요도를 어떻게 매기나

배깅은 모든 나무가 모든 변수를 봤으니 그냥 합산하면 됐다. 랜덤포레스트는 애초에 뽑히지 않은 변수가 있다.

“나는 기회도 못 받았는데, 왜 내 중요도가 0인가?”
PERMUTATION IMPORTANCE

한 변수만
뒤섞어 본다

값을 흔들었을 때 정확도가 무너지면 중요한 변수, 꿈쩍 않으면 안 중요한 변수.

모든 변수를 데이터 전체에 대해 다시 돌려야 해서 아주 느리다. SHAP 도 마찬가지.
한계

“이 변수는 플러스인가 마이너스인가”
— 답할 수 없다

회귀는 계수 부호 하나로 끝났다. 비선형은 구간마다 방향이 다르다. 데이터 한 건이 정해지면 그때의 영향은 말할 수 있지만, 모델 전체의 방향은 한마디로 요약되지 않는다.

BOOSTING

앞이 끝나야
뒤가 간다

직렬이라 느리다. 배깅은 병렬이라 GPU 를 그대로 쓸 수 있지만, 부스팅은 팔짱 끼고 기다린다.

그래서 개별 모델을 아주 약하게 쓴다 — 분기 하나짜리 나무. 이를 weak learner 라 한다.

AdaBoost 를 한 단계씩

원의 크기 = 뽑힐 확률
GRADIENT BOOSTING

XGBoost · LightGBM · CatBoost

알고리즘의 차이는 크지 않다. 속도를 혁신적으로 올렸고, 부스팅에 여러 트릭을 넣었다.
