재표집 ①

K-fold Cross Validation

전체를 K등분해서 한 칸씩 돌아가며 테스트로 쓴다
K-fold 원본 도해 — 10개를 5등분해 다섯 벌의 훈련·테스트 조합을 만든다

한 칸씩 돌아가며 테스트로 쓴다 — 겹치지 않게 나누고, 데이터를 아껴 쓴다.

재표집 ②

Bootstrap

복원 추출
뽑고 다시 넣는다 — 그래서 표본을 무한히 만들 수 있다
Bootstrap 원본 도해 — 같은 데이터가 여러 번 뽑히고, 안 뽑힌 것이 테스트가 된다

뽑고 다시 넣는다. 같은 데이터가 두 번 들어갈 수 있고, 안 뽑힌 것은 그 모델의 테스트가 된다.

BOOTSTRAP AGGREGATING

Bagging

  1. 부트스트랩으로 표본을 여러 벌 만든다
  2. 표본마다 나무를 하나씩 심는다
  3. 마지막에 투표시킨다

Breiman, L. Bagging Predictors. 1994 / Machine Learning 24, 123–140 (1996)

Bagging 다이어그램 — Bootstrap sample n → Learning model n → Aggregation
BAGGING

배깅은 행만 뽑는다

원데이터에서 부트스트랩 세 벌을 뽑아 나무를 셋 심고 합치는 도해

변수는 전부 그대로다. 그래서 강한 변수가 하나 있으면 모든 나무가 그걸 첫 분기로 쓴다 — 나무들이 서로 닮는다.

RANDOM FOREST · 2001

랜덤 포레스트는 열도 뽑는다

부트스트랩마다 쓰는 변수 열까지 달라지는 랜덤 포레스트 도해

어떤 나무는 강한 변수를 아예 못 받는다. 일부러 약하게 만들어 서로 다르게 하고, 그 다양성이 분산을 더 줄인다.

아무 값에서
시작한다

GRADIENT DESCENT ②

얼마나
틀렸나

Loss = ½ Σ(yi − αxi)²
α = 2 일 때 Loss 5,081
전부 넣어보면 4~5 근처가 바닥이다. 그런데 이렇게 다 해보는 건 변수가 하나일 때나 가능하다.
α 에 따른 Loss 곡선
GRADIENT DESCENT ③

미분해서
반대로 간다

∂Loss/∂α = Σxi²α − Σyixi
−∂Loss/∂α

경사의 반대 방향으로 조금씩 움직인다.

Loss 곡선과 그 미분값
GBM 에서의 경사 하강

경사의 반대 방향 = 잔차

min L = ½Σ(yi − f(xi))²
∂L/∂f(xi) = f(xi) − yi
−∂L/∂f(xi) = yi − f(xi) = 잔차

그래서 다음 모델은 잔차를 예측하도록 학습시킨다. 이것이 Gradient Boosting 이라는 이름의 이유다.

GBM Algorithm

Friedman, J. H. Greedy Function Approximation. Annals of Statistics 29(5), 2001
GBM 알고리즘 의사코드
