One-hot · 사전은 여덟 개짜리 예시

어떤 두 단어를 골라도 겹치는 자리가 없다 — “student 와 teacher 가 가깝다”를 적을 방법이 없다.

LSTM 이 다 읽고 남긴 10 개의 숫자

자기가 뱉은 단어를 다시 먹는다

Query / Key / Value / Attention Value
Query — 지금 보고 있는 단어 (검색어)
Key — 비교 대상들 (색인)

3교시 정리
  1. 언어 모델 = 다음 단어의 확률을 계산하는 모델.
  2. Seq2Seq 는 벡터 하나로 접었다 — 길어지면 앞이 사라진다.
