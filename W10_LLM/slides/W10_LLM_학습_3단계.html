Mixture of Experts

라우터는 LSTM 의 시그모이드 스위치와 같은 아이디어다. 데이터로 시키지 않았는데 분야별로 갈라져 학습됐다.

MoE 가 바꾼 것

학습은 더 느리게, 추론은 훨씬 빠르게

학습 — 오히려 느리다

라우터까지 함께 학습해야 한다.

추론 — 훨씬 빠르다

일부만 켜지니 전력과 속도가 함께 좋아진다.

그래서 총 파라미터 와 토큰 하나가 실제 쓰는 활성 파라미터 가 갈라졌다.
어느 쪽인지 밝히지 않은 수치는 강의에서 쓰지 않는다.

사람 없이 채점할 수 있는 것들

RLVR — 검증 가능한 보상

이걸 공개하고부터 수학과 코드 성능이 급격히 올라갔다. 지금 코드 제너레이터가 잘 되는 이유다.

전문 영역의 함정

비슷한 단어가
비슷한 벡터가 된다

일반인에게는 비슷하게 들리지만, 그 안에서는 단어 하나로 법령이 바뀐다.

두 벡터가 완전히 벌어져 있어야 하는데 그렇지 않다.

도시계획도 똑같다 — 용도지역 용어 하나가 그렇다.

큰 행렬 대신 작은 것 둘

LoRA — Low-Rank Adaptation

성능은 조금 떨어지지만 맥락은 맞게 간다. 이미지의 스테이블 디퓨전에서도 같은 기법을 봤다.

2교시 정리
  1. Pre-training — 인터넷 텍스트를 가리고 맞힌다. 라벨링이 필요 없었다.
  2. SFT — 대화냐 사고 과정이냐로 모델의 성격이 갈린다.
  3. RLHF — 자기가 뱉은 답에 점수를 매겨 서비스 가능한 물건으로 만든다.
  4. MoE · RLVR · LoRA · 양자화 — 더 빠르게, 더 싸게, 더 작게.
여기까지 오면 수식은 머릿속에 없어도 된다 — 라이브러리가 다 해 준다. 남는 건 방향성이다.
