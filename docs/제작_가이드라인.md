## 3. 갭 분석 — 제작 전에 결정할 것

### G1. 6주차 주제가 공란
계획서 6주차는 주제·활동사항 모두 비어 있고, 5주차 활동사항에 CNN 기초 + 건물외벽 + Detection/Segmentation + 항공영상이 몰려 노트북 7개(35장)가 180분에 들어간다.
**제안** 5주 = CNN 기초와 학습(11~17), 6주 = "이미지 분석 1-2: 탐지와 분할"(18~20).

### G2. 11~14주 자산이 사실상 없다 — 신규 4주분
MCP·Tool Use, 그래프DB·RIG, 에이전트 오케스트레이션, 하네스는 25년에 없던 내용. 대응 자산은 `30 LLM RAG`·`31 LLAMA INDEX`의 일부 셀과 이미지 10장뿐.
26년 개편의 핵심이자 세부목표3의 평가 근거이므로 제작 공수의 절반 이상을 여기에 배정.

### G3. 배치되지 않은 자산 31장 — 특히 강화학습
수업목표·주요주제에는 RL과 Agent-based Simulation이 명시돼 있으나 주별계획에 자리가 없다.
`36 RL`(7장), `34 CF`(12장), `33 Association`(4장), `32 VLM`(8장).
**선택지** ① 13주 후반 30분에 RL·ABS 편성 ② 추천·연관분석은 2주차 사례로 축약 ③ VLM은 7주 또는 10주 말미 멀티모달 확장.

### G4. 9주차가 시계열과 Transformer를 함께 진다
노트북 6개·38장. **제안** 1교시 = 시계열·RNN·LSTM, 2교시 = 언어모델·Seq2Seq·Attention. 파일도 `W09-1`/`W09-2`로 분리.

### G5. 코드 노후화 — 개강 전 점검
- `hycms.hanyang.ac.kr` 데이터 링크 사용 노트북 **21개** → 링크 유효성 일괄 확인
- `tensorboardcolab` (16 AlexNet) — 유지보수 중단 패키지, import 제거
- `yolov5` 클론 + v5.0 가중치 (19 YOLO) → `ultralytics` 기반 갱신 검토
- `ViTFeatureExtractor` (32 VLM) → `ViTImageProcessor`
- OpenAI 키 필요 노트북 **3개** (28, 30, 31) → 키 발급·예산 정책을 1주차 공지
- TF/Keras **16개** vs PyTorch **4개** 혼재 → 전환 지점을 슬라이드에 명시

### G6. "Open Claw" 표기 확인 필요
13주차 첫 활동 항목. 어떤 도구인지 확정해야 실습 환경·슬라이드 예시가 정해진다. 계획서의 "별도 템플릿 코드 제공"과 함께 13·14주 실습 스택을 먼저 고정.

5. PowerPoint에서 강조·애니메이션·도해 다듬기
6. 강의실 화면 비율로 한 번 넘겨보기 — 14pt 미만·뭉갠 이미지가 여기서 걸린다

```python
from pptx import Presentation
from pptx.util import Inches, Pt
import json

man = json.load(open('_extracted/images_manifest.json', encoding='utf-8'))
picks = [m for m in man if m['week'] == '5주' and m['w'] >= 1200]

prs = Presentation('template.pptx')            # 기존 기계학습.pptx를 템플릿으로
for m in picks:
    s = prs.slides.add_slide(prs.slide_layouts[5])     # 제목만 있는 레이아웃
    s.shapes.title.text = m['cell_text'][:40] or m['notebook']

    w_in = min(11.5, m['w'] / 150)                     # 4절 배치 규칙
    left = Inches((13.333 - w_in) / 2)
    s.shapes.add_picture(m['path'], left, Inches(1.6), width=Inches(w_in))

    cap = s.shapes.add_textbox(Inches(0.6), Inches(6.9), Inches(12), Inches(0.4))
    cap.text_frame.text = f"{m['rel']} · cell {m['cell']}"
    cap.text_frame.paragraphs[0].runs[0].font.size = Pt(10)

    s.notes_slide.notes_text_frame.text = m['cell_text']   # 다음 해를 위한 흔적

prs.save('W05_이미지분석1_CNN기초.pptx')
```

**버전 관리**
- `_extracted/`는 68MB. 저장소에 올릴 필요 없으면 `.gitignore`에 추가 — 노트북만 있으면 재추출 가능
- 완성 pptx는 `slides/` 폴더, 수정본은 `_v2` 대신 날짜(`_260915`)로 구분
