## 주차별 메모

**1주 · 강의 소개** — 기계학습.pptx 의 튜링·로젠블랫 부분을 전용할 수 있다. 평가 배점과 OpenAI 키·예산 정책을 이 주에 공지한다(G5).

**2주 · 데이터 분석 기초 이해** — 회귀분석 강의안(HTML 47쪽)이 이미 있다. PCA·클러스터링은 아직 노트북뿐.

**3주 · 앙상블 알고리즘** — 기계학습.pptx(24슬라이드)가 이 주차의 기존 강의안이자 전체 pptx 규격의 기준.

**4주 · 인공신경망** — MLP 11장이 손계산 도해다 — 역전파를 손으로 따라가는 장면에 그대로 쓴다.

**5주 · 이미지 분석 1 — CNN 기초와 학습** — G1 반영 — 25년에는 5주에 몰려 있던 7개를 5·6주로 나눴다. 16 AlexNet 의 tensorboardcolab import 는 제거 대상(G5).

**6주 · 이미지 분석 1-2 — 탐지와 분할** — G1 이 만든 주차 — 계획서 6주차 주제 공란 자리. 19 YOLO 는 yolov5 v5.0 클론 방식이라 ultralytics 로 갱신 검토(G5).

**7주 · 이미지 분석 2 — 생성모델** — 이미지 46장으로 최다. GAN 계보 9장은 계보 한 장으로 압축하고 나머지는 부록.

**9주 · 시계열·순환신경망·Transformer** — G4 — 노트북 6개·38장이라 한 주에 안 들어간다. 1교시(W09-1) 시계열·RNN·LSTM / 2교시(W09-2) 언어모델·Seq2Seq·Attention 으로 슬라이드를 나눈다.

**10주 · LLM 정렬과 활용** — 28 GPT 는 OpenAI 키가 필요하다(G5).

**11주 · 프롬프트와 증강 생성** — G2 — 신규 4주 중 첫 주. MCP 3계층 도해가 신규. 슬라이드보다 LLM 접근 방식(개인 키/공용 키/로컬)을 먼저 정해야 한다.
