# AGENTS.md — 11주차 codex_lab

Codex 는 이 폴더에서 일할 때 매 턴 이 파일을 읽는다. 07단계에서 이 파일을 **넣기 전과
넣은 뒤**를 비교해 보여 준다 — 프롬프트로 부탁하던 것을 저장소 규칙으로 옮기는 것이
하네스다.

## 이 폴더가 무엇인가
도시빅데이터와 머신러닝 11주차 실습 **웹 앱(FastAPI)**. 2040년 파주 도시기본계획(2026.06 최종
보고서, 721쪽)을 재료로 01 API 호출 → 02 temperature·top_p → 03 system prompt → 04 RAG(llama_index)
→ 05 툴 콜링 → 06 서브에이전트 → 07 하네스를 브라우저에서 한 칸씩 승인하며 따라간다.

## 실행과 구조
- 파이썬은 `.venv` 의 것을 쓴다. 서버: `.venv\Scripts\python -m uvicorn app:app --port 8000`
- 실험은 `labs/s0N_*.py` 의 `run(params)` 제너레이터다. `ask(...)` 에서 멈추고 사람의 승인을
  기다리며, `show(...)` 로 결과 블록을 화면에 보낸다(`labs/runtime.py`).
- **API 를 부르거나 도구를 실행하는 코드는 반드시 그 앞에 `ask(...)` 를 둔다.** 승인 없이
  호출하는 단계를 만들지 않는다 — 이 앱의 핵심이 그 멈춤이다.
- 화면 블록 종류는 `static/app.js` 의 `R` 에 있다. 새 블록을 만들면 거기에 그리는 함수도 같이 넣는다.
- 공용 설정은 `common.py`, 벡터 검색은 `rag.py` 하나로 통일한다. 검색을 다시 구현하지 않는다.

## 하면 안 되는 것
- `data/paju_2040.pdf`, `data/index/` 를 지우거나 고치지 않는다. 원문과 인덱스는 수업 재료다.
- `.env` 내용을 화면에 출력하거나 코드·커밋에 넣지 않는다. 키는 환경변수로만 읽는다.
- 인덱스 재생성(`rag.get_index(rebuild=True)`, 또는 data/index 를 비우고 04 ①)은 돈과 시간이 드므로 **실행 전에 사람에게 묻는다.**
- 새 패키지를 설치하기 전에 묻는다. 설치했으면 `requirements.txt` 에 적는다.

## 답할 때 지킬 것
- 파주 계획의 수치·명칭을 말할 때는 `rag.search()` 결과에서 가져오고 **(p.N)** 을 붙인다.
  보고서에서 못 찾으면 지어내지 말고 "보고서에서 찾지 못함" 이라고 쓴다.
- 웹에서 가져온 내용은 매체명과 URL 을 붙이고, 보고서 근거와 섞지 않는다.
- 쪽 번호는 PDF 뷰어 기준이다(본문에 찍힌 쪽 번호와 약 12쪽 차이).

## 실패해서 알게 된 것
- 모든 쪽 머리에 `2040년 파주도시기본계획 - 37 -` 이 찍혀 있어, 지우지 않으면 짧은 질문에
  이 머리글끼리 닮았다고 엉뚱한 쪽이 검색됐다. `rag.page_text()` 가 지운다.
- 02단계의 temperature·top_p·logprobs 는 `gpt-4.1-mini` 로 고정한다.
- OpenAI 내장 web_search 를 모델에 그대로 주면 OpenAI 서버 안에서 실행돼 승인할 틈이 없다.
  그래서 `labs/tools.py` 에서 우리 함수로 감쌌다.
- temperature=0 이어도 다섯 번이 완전히 같지 않을 수 있다(서버 쪽 비결정성). 버그가 아니다.
- 지시문으로 "쪽 번호를 붙여라"고 해도 빠뜨린다(05단계). 그래서 07단계는 출력을 검사한다.
