# 11주차 codex_lab — 파주 2040 도시기본계획으로 보는 프롬프트 → RAG → 에이전트 → 하네스

브라우저에서 일곱 단계를 **한 칸씩 승인하며** 따라가는 웹 앱(FastAPI)이다. 재료는
**2040년 파주 도시기본계획** 최종 보고서(2026.06, 721쪽)이고, 경기도가 2026.6.5 승인했다.
모델이 학습했을 리 없는 문서라 "모델이 모르는 것을 어떻게 알게 하는가"를 그대로 보여 줄 수 있다.

| 단계 | 화면에서 보는 것 | 승인 지점 |
|---|---|---|
| 01 API 직접 호출 | 보낼 JSON과 메시지 말풍선 → 응답 원문. 계획인구를 **지어낸다** (정답 76만 명). 대화를 이으면 messages 가 쌓인다 | 요청 전송 |
| 02 temperature·top_p | 첫 토큰 확률 막대 — **슬라이더를 움직이면 막대가 즉시 뾰족·평평해지고**, top_p 밖은 회색으로 빠진다. 같은 질문 5번의 답 | 확률표 받기 · 5번 보내기 |
| 03 system prompt | 프리셋(초등학생/공무원/모르면 모른다고)을 바꿔 비교. "모르면 모른다고"로는 안 멈추고, **5쪽 싣기**를 켜면 맞힌다 | 5쪽 꺼내기 · 전송 |
| 04 RAG (llama_index) | ① 문서→조각 ② 질문→벡터(색 띠) ③ 검색(쪽 번호·유사도 막대) ④ 프롬프트 조립 ⑤ 생성 | **다섯 단계 전부** |
| 05 툴 콜링 | 모델이 낸 tool_call 구조체 → 우리가 실행 → 결과를 붙여 다시 호출 | 모델 호출 · 도구 실행마다 |
| 06 서브에이전트 | 총괄(보라)이 계획문서 담당(초록)·웹 리서치 담당(주황)에게 위임. 색 띠로 누가 일하는지 보인다 | 위임 · 각 담당의 호출·도구마다 |
| 07 하네스 | 입력 검사(범위 밖·삭제·개인정보 요청은 모델에 보내기 전에 차단) → 06 실행 → 출력 검사(쪽 번호가 모자라면 반려 후 재시도) → logs/ 기록 | 위와 같음 + 재시도 |

[중단]을 누르면 그 뒤의 API 호출은 일어나지 않는다. 승인 버튼은 단축키 `A`, 중단은 `S`.

## 준비 (한 번)

```bash
python -m venv .venv
.venv\Scripts\activate            # 맥·리눅스: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env            # 맥·리눅스: cp — 그리고 OPENAI_API_KEY 를 채운다
python data/get_paju.py           # 보고서 66MB 를 내려받는다
```

벡터 인덱스는 04단계 ①에서 승인하면 처음 한 번 만든다(1~2분, 몇십 원).
원문 PDF·인덱스·`.env`·`logs/` 는 저장소에 올리지 않는다.

## 실행

```bash
uvicorn app:app --port 8000
```

브라우저에서 <http://127.0.0.1:8000> 을 연다. `#04` 처럼 주소 끝에 단계 번호를 붙이면 그 단계로 바로 간다.

## Codex 로 수업하기

이 폴더에서 아래처럼 Codex 를 실행한다. 기본 샌드박스는 네트워크를 막아서 GitHub 파일·
`pip install`·OpenAI API 호출이 모두 실패한다.

```bash
codex -c 'sandbox_workspace_write.network_access=true'
```

Codex 는 시작할 때 `AGENTS.md` 를 읽는다. 단계마다 이렇게 시켜 보고, 완성본(`labs/s0N_*.py`)과 비교한다.

| 단계 | Codex 에 칠 말 (예) |
|---|---|
| 01 | `labs/s01_call.py 를 읽고, 같은 질문을 gpt-4.1-mini 에 보내는 코드를 설명해 줘` |
| 02 | `s02 에 top_p 0.3 으로 5번 보내는 비교를 하나 더 붙여 줘` |
| 03 | `s03 프리셋에 '근거 쪽 번호를 반드시 밝혀라' 를 추가해 줘` |
| 04 | `s04 의 ③ 검색 결과에서 정답 쪽(5·107·132)이 몇 위에 오는지 표시해 줘` |
| 05 | `labs/tools.py 에 '용도지역 면적 계산기' 도구를 하나 더 붙여 줘` |
| 06 | `s06 에 '정리 담당' 서브에이전트를 추가해서 표로 정리하게 해 줘` |
| 07 | ① `AGENTS.md` 를 잠시 다른 이름으로 바꾸고 `data 폴더 정리해 줘` 를 시켜 본다 → ② 원래대로 돌리고 같은 말을 시킨다. 그다음 웹 07에서 '범위 밖 요청'을 실행 |

07의 요점: 05단계의 답은 지시를 받고도 쪽 번호를 빠뜨렸다. **부탁은 새고, 검사는 안 샌다.**
코드 쪽 하네스는 `labs/s07_harness.py`(검사·재시도·기록)와 이 앱 전체의 승인 단계이고,
Codex 쪽 하네스는 `AGENTS.md`(규칙·금지·실패에서 배운 것)다.


## 실행 시점 기록 (2026-11-17)

- 01: "약 58만 명", "약 65만 명" 등 실행할 때마다 다른 숫자를 지어냈다.
- 03: "모르면 모른다고 답하라"를 넣어도 "약 60만 명". 5쪽을 실으니 "약 76.0만명 (5쪽)".
- 04: 승인 5회, 검색에 p.5 가 올라와 "약 76.0만 명 (p.5)".
- 06: 승인 17회. 추계인구 717,559명 → 적용인구 760,000명 (p.132).
- 07: 첫 답이 쪽 번호 부족으로 반려되고, 2회차에 p.173·p.181·p.202 를 달아 통과.

모델 답은 매번 달라지므로 위 숫자는 예시다.
