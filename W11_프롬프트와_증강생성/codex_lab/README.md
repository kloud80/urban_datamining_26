# 11주차 codex_lab — 파주 2040 도시기본계획으로 보는 프롬프트 → RAG → 에이전트 → 하네스

강의안 순서 그대로 일곱 단계를 코드로 따라간다. 재료는 **2040년 파주 도시기본계획**
최종 보고서(2026.06, 721쪽) — 경기도가 2026.6.5 승인했다. 모델이 학습했을 리 없는
문서라서 "모델이 모르는 것을 어떻게 알게 하는가"를 그대로 시연할 수 있다.

| 단계 | 파일 | 보여 주는 것 | 덱 |
|---|---|---|---|
| 01 | `01_call.py` | user 한 줄로 부르면 계획인구를 **지어낸다** (정답 76만 명) | 오늘의 질문 |
| 02 | `02_sampling.py` | 확률표가 온도에 따라 뾰족·평평해지고, 같은 질문 5번의 답이 갈린다 | 6–10쪽 |
| 03 | `03_system_prompt.py` | 역할로 말투는 바뀌지만 "모르면 모른다고 해"로는 **안 멈춘다**. 5쪽을 실으면 맞힌다 | 12–16쪽 |
| 04 | `04_rag.py` | 721쪽을 벡터로 바꿔 두고, 가까운 조각만 골라 싣는다 (llama_index) | 17–20쪽 |
| 05 | `05_tools.py` | 보고서 검색 + 웹 검색을 도구로 주고, 호출 → 실행 → 결과 왕복을 화면에 찍는다 | 21–24쪽 |
| 06 | `06_subagents.py` | 총괄이 계획문서 담당·웹 리서치 담당에게 나눠 맡긴다 (OpenAI Agents SDK) | 하네스 8–9쪽 |
| 07 | `07_harness.py` + `AGENTS.md` | 입력을 막고, 쪽 번호 없는 답은 반려해 다시 시키고, 기록을 남긴다 | 하네스 7·10–14쪽 |

## 준비 (한 번)

```bash
python -m venv .venv
.venv\Scripts\activate            # 맥·리눅스: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env            # 맥·리눅스: cp — 그리고 OPENAI_API_KEY 를 채운다
python data/get_paju.py           # 보고서 66MB 를 내려받는다
python 04_rag.py                  # 처음 한 번 인덱스를 만든다 (1~2분, 몇십 원)
```

원문 PDF·인덱스·`.env`·`logs/` 는 저장소에 올리지 않는다.

## Codex 로 수업하기

이 폴더에서 아래처럼 Codex 를 실행한다. 기본 샌드박스는 네트워크를 막아서 GitHub 파일·
`pip install`·OpenAI API 호출이 모두 실패한다.

```bash
codex -c 'sandbox_workspace_write.network_access=true'
```

Codex 가 `AGENTS.md` 를 읽고 시작한다. 단계마다 아래처럼
시키고, 막히면 완성본 파일을 실행한다.

| 단계 | Codex 에 칠 말 (예) |
|---|---|
| 01 | `openai 로 gpt-4.1-mini 에 "2040년 파주 도시기본계획의 계획인구는?" 을 한 번 물어보는 스크립트를 만들고 실행해 줘` |
| 02 | `같은 질문을 temperature 0, 1.0, 1.5 와 top_p 0.3 으로 5번씩 보내고, 첫 토큰 logprobs 상위 5개도 보여 줘` |
| 03 | `system prompt 를 세 가지로 바꿔 비교하고, 마지막엔 보고서 PDF 5쪽 원문을 system 에 실어서 다시 물어봐` |
| 04 | `data/paju_2040.pdf 를 llama_index 로 인덱싱하고 쪽 번호와 함께 답하게 해 줘` |
| 05 | `rag.search 를 함수 도구로, web_search 를 내장 도구로 주고 도구 호출 왕복을 출력해 줘` |
| 06 | `Agents SDK 로 계획문서 담당·웹 리서치 담당 서브에이전트를 만들고 총괄이 나눠 맡기게 해 줘` |
| 07 | ① `AGENTS.md` 를 잠시 다른 이름으로 바꾸고 `data 폴더 정리해 줘` 를 시켜 본다 → ② 원래대로 돌리고 같은 말을 시킨다. 그다음 `python 07_harness.py --off-topic` |

07의 요점 — 05단계의 답은 지시를 받고도 쪽 번호를 빠뜨렸다. **부탁은 새고, 검사는 안 샌다.**
코드 쪽 하네스는 `07_harness.py`(가드레일·재시도·턴 상한·기록), Codex 쪽 하네스는
`AGENTS.md`(규칙·금지·실패에서 배운 것)다.

## 실행 시점 기록 (2026-11-17)

- 01: "약 58만 명", "약 65만 명" 등 실행마다 다른 숫자를 지어냈다.
- 03: "모르면 모른다고 답하라"를 넣어도 "약 60만 명". 5쪽을 실으니 "약 76.0만명 (5쪽)".
- 06: 추계인구 717,559명 → 적용인구 760,000명 (p.132), 산정 지침 (p.127).
- 07: 첫 답이 쪽 번호 1개로 반려되고, 2회차에 p.173·p.202 를 달아 통과했다.

모델 답은 매번 달라지므로 위 숫자는 예시다.
